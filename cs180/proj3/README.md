# CS180 Project 3

A static project report with Part A and Part B results and explanations. Part B includes all 26 saved notebook figures: denoising, unseen noise levels, pure-noise training, time-conditioned flow matching, and class-conditioned generation with and without a learning-rate scheduler. The only scripted interaction is rotating the Part A visual anagrams. No notebooks, project implementation files, or extraction scripts are included in the hosting folder.

Open index.html in a browser, or preview from this directory with:

    python3 -m http.server 8033 --bind 127.0.0.1

There is no build step. Changes are intentionally uncommitted and unpublished.
